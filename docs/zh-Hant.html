讓每一個編碼代理都能用對成熟的無障礙工具。

Beacon 是 Claude Code 與 Codex 的無障礙整合層。它結合原始碼檢查、瀏覽器量測、axe-core 證據、Lighthouse 補充訊號與人工測試指引，再把證據整理成有優先序、能直接對照程式碼的修正工作。

高分的意思是：自動化檢查在現有證據裡找到的問題較少。它是分診信號，不是合規證書，更不能取代與身心障礙使用者的實際測試。

開始使用 看本頁自己的檢測報告

同一個工作流程，讓適合的工具提供證據

Beacon 不取代成熟的檢測引擎。它保留每個工具真正證明了什麼、把不確定結果留給人工覆核、避免同一問題重複扣分，並告訴代理接下來還需要誰來驗證。

Beacon 原始碼檢查

部署前、沒有瀏覽器時也能執行，找出程式碼模式、檔案位置與代理可直接採取的修法。

axe-core

檢查實際渲染內容；通過、違規、待人工判定、不適用、受影響節點、規則連結、引擎版本與來源都完整保留。

Lighthouse

補充效能、Best Practices 與 SEO。Accessibility 類別本身使用 axe-core，因此不當成另一份獨立證據重複計算。

WAVE / WebAIM

規劃作為使用者自行提供存取權時的選配交叉檢查，目前尚未進入預設流程。Beacon 不會內附付費 API 金鑰，也不會把 WAVE 結果說成自己的發現。

人工與輔助科技測試

涵蓋鍵盤任務、NVDA、VoiceOver、認知理解、動態效果與實際使用；任何自動分數都不能取代這一層。

整合後的報告會保留每一份證據的來源與版本。不同工具互相印證時會加強可信度，不會重複處罰。

一個插件，三個時機

無障礙在寫程式之前處理最便宜，上線之後處理最貴。Beacon 在三個時間點都接得上。

動工之前

beacon:guide

無障礙設計模式、對比安全的配色、字級與動態效果的預設值，還有取捨建議——在介面還是草圖的時候就給。

寫碼當下

beacon:advisor

掛鉤（hook）即時審每一次介面修改，把該檔案的具體檢查清單直接交給代理。

寫完之後

beacon:inspect

Lighthouse 風格的 0 到 100 分報告：修法錨定到原始碼、六個司法管轄區的法規脈絡、跨次執行的前後對照。

每個偵測器都帶著自己的實測精度

3,625 排除狀態不符資料後，目前進入彙總分析的有效產物
0 個具名網站 公開的是彙總量測，不是針對第三方網站的公開排名

這批資料不代表 3,700 個網站都經過人工稽核、不代表每一條 finding 都正確，也不能把分數分布解讀成整個網路的無障礙品質。請讀母體定義與允許主張。

它會不會跟你的設計美感打架？

問題按「對頁面預設外觀的影響」分成三類。

零像素 替代文字、無障礙名稱、標籤關聯、標題層級、頁面語言、結構化資料
僅特定狀態 只在使用者自己選擇的狀態下出現——鍵盤焦點、縮窄視窗、減少動態
文案，非風格 連結措辭或驗證機制——內容決定，不是視覺風格

大部分的無障礙欠債，對沒被它擋住的人是隱形的。修掉它不會動到你的美感——本頁就是示範：想怎麼設計就怎麼設計，然後用它宣傳的引擎檢測自己，報告一鍵可查。

安裝

先註冊插件市集，之後在 Claude Code 裡一行指令。

/plugin install beacon@beacon

格式是「插件名@市集名」。這個版本庫同時是市集本身與其中唯一的插件，兩者同名，所以看起來是疊字。

先把市集加進 Claude Code 設定：

"extraKnownMarketplaces": {
  "beacon": {
    "source": { "source": "github", "repo": "chiehweihuang/beacon" }
  }
}

使用 Codex？以原生插件方式安裝：

codex plugin marketplace add chiehweihuang/beacon
codex plugin add beacon@beacon

安裝後請重新啟動 Codex。執行環境差異請見 ADAPTERS.md。

需要修復協助嗎？

Beacon 的維護者提供 AI 輔助開發情境的無障礙顧問服務——檢測結果的修復協助、AI 產出介面的無障礙驗證、自動化層之外的深度審查（鍵盤走查、輔助技術實測、法規脈絡），對中日台市場的產品有特別深的著墨。
